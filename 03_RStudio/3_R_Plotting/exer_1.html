Task 1: Create and customize a scatterplot

============================================================================

Create a scatterplot of sleep_total vs bodywt (body weight).

Customize your plot with:

- A point character (pch) of your choice

- Blue colored points

- Axis labels: “Body Weight (kg)” for x-axis and “Total Sleep (hours)” for y-axis

- A border style of your choice (bty)

Your code here:

plot(msleep$bodywt ~ msleep$sleep_total, pch = 16, col = "blue", xlab = "Body Weight (kg)", ylab = "Total Sleep (hours)", bty = "C")

Task 3: Create a boxplot comparing groups

============================================================================

Create a boxplot showing sleep_total for each vore type (diet).

Customize your boxplot with:

- Different colors for each box (hint: use rainbow() or choose specific colors)

- Appropriate axis labels

- Convert vore to a factor using as.factor()

Your code here:

plot(msleep$sleep_total ~ as.factor(msleep$vore), col = c("darkorchid", "orchid", "salmon", "sienna"), xlab = "Vore Type", ylab = "Sleep Total (hours)")
